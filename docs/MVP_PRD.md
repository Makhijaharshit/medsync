# MVP PRD

## Objective
Upload medical documents, extract structured data with AI, verify it, build a longitudinal timeline, and expose an emergency profile.

## Users
- Patient
- Doctor
- Paramedic
- Admin

## Core Features
1. Authentication
2. Document upload
3. OCR + AI extraction
4. Verification workflow
5. Medical timeline
6. Emergency profile
7. SOS
8. Audit logs

## Acceptance Criteria
- Upload PDF
- OCR completes
- Verification required
- Timeline updates
- SOS creates emergency event
- Unauthorized users blocked
